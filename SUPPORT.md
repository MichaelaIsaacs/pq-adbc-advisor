# Support

## How to get help

* **Product questions** (does my connector migrate? what should my
  gateway look like?) — email `adbcmigration@microsoft.com` or ask in
  the Microsoft Fabric community on Reddit.
* **Bug reports & feature requests** — open a GitHub issue on this
  repository using the templates in `.github/ISSUE_TEMPLATE/`.
* **Security issues** — see `SECURITY.md`. Do not open a public issue.

## Support scope

`pq-adbc-advisor` is a **preview tool** developed by the Power Query
PM team as part of the ODBC → ADBC migration campaign. It is not
covered by Microsoft's standard commercial support agreement.

For questions specifically about the migration campaign itself
(timelines, connector coverage, official documentation), the
canonical reference is
[Transition to ADBC on Microsoft Learn](https://learn.microsoft.com/power-query/transition-to-adbc).

## Response expectations

The maintainers work on this tool as part of the ODBC → ADBC campaign,
not as a full-time support product. Expect a response to GitHub issues
within roughly one business week during the campaign; longer once the
campaign concludes.
